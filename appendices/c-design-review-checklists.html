Appendix CDesign-Review Checklists

Use these lists in every design review. Each item points to the section that explains it; the numbers are the targets of Table 14.2.

Transmitter

  • FO4 measured in the PDK; CMOS stages close timing at the slow corner (Section 9.2).

  • Half-rate mux: glitch-free phases, duty cycle \(50\pm1\) %.

  • Driver \(I_T\) for 0.8–1.0 Vppd; every \(V_\mathrm{CE}<\mathrm{BV}_\mathrm{CEO}\) at \(V_\mathrm{CC}+5\) %, with the real far-end termination.

  • FFE presets \(-3.5\)/\(-6\) dB exact within one LSB; tap paths matched to a few ps.

  • Termination trimmed to \(\pm10\) %; \(C_p\le0.85\) pF; RL \(\ge10\) dB at \(f_\mathrm{N}\).

  • Post-layout eye through REF within 10 % of the model.

Channel and board

  • Loss at \(f_\mathrm{N}\) (not \(f_\mathrm{b}\)) known; REF replaced by measured S-parameters.

  • Via stubs short or back-drilled; first resonance above 5 GHz.

  • Pairs length-matched; TX and RX pairs separated (NEXT).

  • SMA launches and bond wires modeled; reflections in the pulse tail checked.

Receiver

  • CTLE: 0–12 dB at every corner; \(f_{p2}\) with the real sampler load.

  • DFE tap-1 loop \(\le1\) UI post-layout; unrolling ready if not.

  • Sampler \(\sigma\le1\) mV; offset DAC \(\ge\pm3\sigma\), 5 bits; \(\tau\le5\) ps.

  • Two extra latches behind the edge samplers (metastability).

  • All four samplers simulated together (kick-back).

  • Deserializer FIFO and recovered-clock domain crossing checked.

PLL and clocks

  • VCO tunes 2.5 GHz with \(V_\mathrm{ctrl}\) mid-range at all corners; band code range covers PVT.

  • Loop: 60\(^\circ\) phase margin, \(f_u\approx3\) MHz, \(f_\mathrm{ref}/f_u\ge10\).

  • VCO phase noise simulated open-loop; RJ \(\le1\) ps rms integrated.

  • Loop-filter capacitors MIM, not leaky MOS.

  • I/Q error \(\le2^{\circ}\) (\(3\sigma\)), duty cycle \(50\pm0.5\) % after DCC.

  • Clock buffers have 2–3\(\times f_\mathrm{clk}\) bandwidth.

CDR

  • Phase-detector truth table verified for both half-rate phases.

  • \(K_P\) from the JTOL slew requirement; \(K_P/K_I\ge16\) (baseline 128).

  • Latency counted in updates; wander \(\le20\) ps pp in simulation.

  • Integral register covers \(\pm300\) ppm; lock \(<1\) s.

  • PI INL \(\le1^{\circ}\) at all 64 codes; code wrap glitch-free.

  • Lab 7 model rerun with the real PI and latency.

Tape-out

  • DRC clean (KLayout decks), antenna and density after fill.

  • LVS clean per macro and full chip without black boxes.

  • Post-layout corners and Monte Carlo pass in CACE.

  • Model back-annotated with extracted responses; margin \(>0\).

  • ESD on every pad; supply domains, decaps and guard rings reviewed.

  • Test access: PRBS, checker, loopback, PI override, clock monitor.

  • Bonding diagram, pinout and test-board plan signed off.
